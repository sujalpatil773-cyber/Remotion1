# Gemini AI — 15s Motion Ad

A 15-second 1920×1080, 60fps Remotion composition built as a polished product-film concept inspired by the supplied Gemini reference assets.

## Composition

- `GeminiAd` — 900 frames / 15 seconds / 60fps / 1920×1080
- Six timed scenes: spark → prompt → reasoning → creation → hero result → end card
- Procedural Gemini sparkle SVG, soft Google-style gradients, depth, spring motion, floating UI cards, cursor choreography and cinematic transitions.

## Run

```bash
npm install
npm run studio
```

Then select `GeminiAd` in Remotion Studio.

## Render

```bash
npm run render:gemini
```

Output: `out/gemini-ad.mp4`

The composition is intentionally self-contained so it renders without depending on remote image URLs or browser-only effects. The uploaded phone/logo references were used as the visual direction for the recreated assets.
